# GranGaler-adePersonajesIlustresdelPer-
Plataforma web interactiva para secundaria que reúne personajes clave de la historia del Perú y Arequipa/Hunter. Incluye buscador, filtros por categorías, fichas con biografías resumidas, datos curiosos y un formulario integrado para enviar sugerencias de nuevos personajes directamente al correo de contacto.
